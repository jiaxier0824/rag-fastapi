# 2026-10-18 收尾版本验证

本次选择已完整验证的 **44/51（86.3%）版本**作为收尾版本。它不是零错误版本；该百分比是现有题集的自动综合规则通过率，不是人工答案准确率或片段检索精确率。

## 保留的改动

- RRF 根据向量与 BM25 两路排名累计分数、按切片去重后直接取 Top-K；移除融合后的路线配额，不改课程/周次范围检索或相邻上下文恢复。
- Agent 主模型及 RAG 翻译、生成模型使用 qwen-flash；Agent 备用模型仍为 qwen-plus。Embedding 仍为 text-embedding-v4，重排仍为可选的 qwen3-rerank。
- Agent 从项目 Settings 显式向主、备模型传递密钥，使用 SecretStr 隐藏配置打印中的密钥；示例配置同步。

## 后续实验没有纳入收尾代码

随后试验过给精排切片附来源文件名，以及对 RAG/Agent 增加作答范围约束。局部复测曾改善，但组合版本完整回归仅 41/51（80.4%），不能据局部通过宣称整体提升。该实验已撤回。

只保留来源信息的另一批复测，在用户选择 86.3% 基线后停止，属于未完成批次，不作为完整评分依据。最终恢复的是上述 44/51 批次对应的代码状态：添加文档前，两仓库受跟踪差异的 SHA-256 均与该批完整测试的记录一致。没有进一步调参、改评分或按题目写入答案。
